Conversor para Markdown

Converte PDF, Word, PowerPoint e Excel em Markdown (.md), mais leve para usar com o Claude e outras IA.

📂 Clique ou arraste os ficheiros para aqui PDF · DOCX · PPTX · XLSX · XLS · CSV · HTML · TXT — vários de uma vez 

    


    

        Os ficheiros são lidos só no browser e não são enviados para nenhum servidor.
        PDFs digitalizados (só imagem) não têm texto para extrair. Imagens e gráficos perdem-se,
        e as tabelas dos PDFs saem como texto corrido; nas de Word, PowerPoint e Excel a estrutura mantém-se.
